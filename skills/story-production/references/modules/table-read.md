# 对白读演与表演节奏校准

用于对白读不顺、镜内台词塞不下、人物口气相似或录音前准备。模拟朗读与真实音频计时分开，未出声录制不能声称完成演员读本。

为每轮指定目的：信息清楚、人物声音、关系策略或时长。一次只改主要问题，避免为了省半秒把所有人物都改成短句机器。

把整场对白按角色抽出，但保留必要动作、对方上一句、情绪转折和声场。找句子中容易误断的主语、代词、数字和专名；专有名词读音需要统一表，不能每集不同。

读演记录`台词ID｜角色目的｜呼吸/停顿｜重音建议｜听者反应空间｜实际或估计时长｜需调整的镜号`。改变镜长后同步字幕和生成分段。字速报警可以发现明显过密，不能决定一切悲伤、紧张或幽默的读法。

比较同一句在不同压力下的两种表演，保留人物真实习惯，不让每句话都成为情绪峰值。画外、电话和录音应有相应声音空间；只有镜内说话者生成口型。

输出可读的读本、修改后的实际台词与录音提示。重复音频先制作唯一母文件，再放入各出现位置，不因读演润色使“同一段录音”前后词句不同。
