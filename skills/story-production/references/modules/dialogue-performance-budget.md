# 对白表演与时间分配

先写人物正在用语言做什么，再估计台词可在怎样的语速、呼吸和动作中完成。计时区分估计、真实读演和录音，不能把字符公式当秒级口型真值。台词过密时选择改表达、改镜长或改结构，不默认加速声音。

可见说话者绑定实际可见人物；画外音、电话、录音和旁白不自动让画面中的人开口。字幕全文、配音文本与画面表演提示分别保留。改写原台词说明动机、意义与人物声音是否改变。

必要的反应、物件动作和交流空隙也占时间。说完一整句不一定就该切，听懂或改变策略可能发生在之后。不同语言的速度统计分别看，超出经验阈值只提示读演，不强制删到统一字数。
