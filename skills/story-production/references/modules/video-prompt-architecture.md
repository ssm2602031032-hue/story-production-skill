# AI视频提示词的层次

把剧作意图、视觉提示词、生成参数和后期要求分开。模型能直接生成的是可见动作与声音，不是“这一镜完成主角成长”“这是第几幕”等编剧说明。

一个镜头先写主体与主要行动，再给空间、身体朝向、运动幅度、机位和动机光。选择一套一致的摄影指令；固定机位同时绕人360度、慢推同时快速拉远属于冲突，应拆镜或明确时序。

资产锁定、首帧与尾帧是制作条件；参考图应真实存在且获批，文字里写资产ID不会自动加载那张脸。台词和画外声单独给出，避免所有听者同时张口。

不同模型与工作流采用不同能力字段。提示词篇幅按模型官方建议与本镜信息密度调整，禁止把“8K、顶级、大片、超真实”堆叠当作质量证据。负向词只针对具体失败与所用管线，不能复制一长串彼此矛盾的禁令。

输出可复制正向文本、必要负向文本、独立参数表和检查点。例文是原创写法示范；未实际生成、对比或盲评时，不称市场最优。
