# 按当前情境选择剪辑策略

先识别当前场景在完成对话策略、悬疑揭示、喜剧兑现、关系试探、行动、说明、蒙太奇、产品演示、纪实表达还是静观体验。整部片的类型不是每一场的剪法；必要时一场内部也可分段改变注意中心。

对话切给真正受到影响的人；悬疑保护线索与答案顺序；喜剧要看清铺垫和反应；动作保留空间与接触；说明给文字/步骤可读时间；纪实不能拼接半句制造新立场。使用策略库时写出本场具体理由，不只挑一个类别。

没有统一每秒必须切、高潮必须越来越快或所有停顿都删的规则。用实际表演与当前事件校准长度，技术工具只报告矛盾和保护区间，观感需要观看整个段落。

工具、输入和使用边界见[剧本到情境剪辑](../script-to-edit.md)。
