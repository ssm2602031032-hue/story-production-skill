# 风格到可见条件

风格词先转成当前作品中的光源、色彩、反差、材质、焦点层次、机位动机、剪辑和声音。预设仅作起点，任意新风格都可按这些维度重写；不要把风格标签当成生成质量开关。

项目级原则与单镜指令分开。一部片允许固定、跟拍、主观镜，不表示每镜要同时做三种运镜。音效、剪辑节奏和后期颗粒也不能都交给一个纯视频提示词。单镜编译要保留唯一明确的动作和机位。

换风格后核对方向是否仍符合用户意图：可以更冷、更轻盈或更奢华，但不能擅改人物、产品本色、车型、剧情动作或时长。完整风格对比和单因素诊断分开，输出观感必须在实际样片上判断。

字段、例子与工具用法见[通用影像执行手册](../visual-reliability.md)。
