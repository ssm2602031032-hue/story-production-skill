# 字幕与配音本地化

先固定人物名、称谓、地名、口头禅与字幕语言版本，再翻译对白。保留潜台词和情境中的意图；笑点、押韵和双关需要功能等效改写并说明损失，不机械逐字翻译。

字幕和配音是不同文本任务：字幕要能读完，配音要真实读演和口型/呼吸校准。工具compare仅检查一对一SRT的时间变化和文本差异，不判断翻译正确，不凭字数认证可配音。确需拆合条目时先建立映射，而不把顺序错位视作正常对应。

Subtitle Edit作为实际波形、视频与字幕手工复核的可选工具；本包不安装它或启用在线翻译。语言内容与声音均未完成时分别标待翻译、待录音和待校时。

字段、运行命令与验证范围见[交付扩展手册](../delivery-extensions.md)。
