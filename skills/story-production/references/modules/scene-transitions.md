# 场景桥接与转场

用于段落跳跃、生硬换场、说明太多或读者找不到时空。先检查前一场留下了什么需要，下一场为什么由此发生，再考虑漂亮的转场技巧。

桥接可能只需一个动作、一个时间标记或一条已知路线；也可能缺的是重大决定，不能靠字幕补掉。区分省略了可以推知的日常过程与跳过了观众需要看的冲突。

影视可使用动作、视线、声音、物件、构图或因果来连接。相似构图不等于同一空间；同一声音延续也不能使原本不在场的角色瞬间到达。空间轴线、时间流逝和道具持有人要在转场前后核对。

小说转章需要明确感知者或时间层改变的入口。非线性结构可以延迟解释，但不能每段都强迫读者重新猜谁在什么时候。一次转场只改变过多变量时，留一个可识别的锚点。

重复场景进入时先表现状态差异：桌上杯子少了、人没坐原来的位子、门变成锁着。不能每次用同样建立镜重播所有布景。过桥戏完成需要后及时离开，保留真正有作用的余韵。

输出前段尾部、桥接和后段开头的连贯文本；如果缺失的是上游行动，明确指出，而非用“后来一切准备妥当”掩盖。
