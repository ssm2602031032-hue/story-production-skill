# 画布增量整理与跨工具交接

新增素材时保留已有稳定ID与可复用位置，尊重用户手工固定的区域。当前布局放不下时报告冲突、分组过密或跨组重叠，再在授权范围内分板；不要把整张画布随机重洗。

原始媒体与画布说明分开，记录文件哈希和相对路径。移动画布时一起携带详情和所需媒体副本；原始源文件不被覆盖。已生成/已批准状态须有真实文件或审看依据，版面整齐不代表内容已经完成。

JSON Canvas是开放的规划数据格式，ComfyUI、React Flow、Excalidraw等还有各自执行或编辑语义。没有适配时保留通用文件与检查结果，不改扩展名冒充；整理可执行节点图时不能擅改模型参数、端口或连线。

长片/整季采用总览与分场景、分段子板，维护全部镜头到页面的映射，检查拆分后没有遗漏。原生应用中的路径解析和交互需要实际试开，不能以JSON可解析代替。

详见[画布手册](../canvas-handbook.md)。
