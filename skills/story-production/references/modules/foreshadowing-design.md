# 伏笔、承诺与回收

伏笔不只是暗藏物件，也可以是能力、误读、关系习惯、未完成的承诺。先问回收改变什么，再决定第一次怎样自然出现。

记录首次出现、当前显义、真正作用、谁注意到、预计回收位置和必要重复。重要信息需要可被记住，隐蔽不是让读者完全无法察觉；重复时改变人物态度或使用方式，而非照搬介绍。

回收必须利用已经建立的性质。普通饰物在结尾突然有万能功能属于新增设定。假线索也需有真实来源，揭露后能解释此前的观察。

用creative-ledger中的promises保存位置与状态：计划中的回收不能标resolved。开放结局可保留部分承诺，但说明为何留白。删掉铺垫场后检查所有依赖，不能只删正文不改结局。
