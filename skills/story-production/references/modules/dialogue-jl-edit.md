# 对白剪辑与J/L声音桥

J-cut可让下一场声音先进入，L-cut可让前场声音延续到反应画面；先明确叙事动机，再确定实际声音和画面的时间位置。声音持续不意味着说话者必须入画，也不能凭画面切换自动重录同一句话。

选择句子边界时听完整语义、词尾、呼吸和接话。新旧环境底噪用连续室内声或适当音量过渡承接，不将每个停顿剪成绝对静音。短淡入淡出用于减少爆点，不能隐藏词被切断。

本包可以独立放置48kHz WAV、增益和音频淡化，并真实渲染预览。OTIO中的增益/淡化只作元数据交接，原生软件须重建；不要把工程打开就当作混音已应用。

具体字段、命令、依赖与执行边界见[剪辑工作台手册](../editing-handbook.md)。
