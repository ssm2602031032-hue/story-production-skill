# 镜间交出、接收与替代覆盖

相邻镜分别说明前镜交出了什么、后镜从何种状态接收、为何此时切，以及声音是否跨越画面。动作匹配、反应、视线、声音桥、对照和有意跳切用途不同，不能统一写“自然衔接”。

需要严格连续动作时核对物件、手、方向和接触状态；其他情况可以用反应、插入或空间桥接实现可剪连续，不必每两镜都强求像素相同的首尾帧。跨空间/时间改变要给观众可识别依据。

对复杂生成失败提前准备覆盖替代：保留同一戏剧功能，降低单镜复杂度。分镜板用于审看，带文字和多格的版面不能默认为视频模型的干净首帧。新剪辑邻接出现时重写边界，不沿用已经删除的过渡镜说明。

工具、输入和使用边界见[剧本到情境剪辑](../script-to-edit.md)。
