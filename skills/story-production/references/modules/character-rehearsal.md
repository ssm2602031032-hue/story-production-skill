# 角色有限知情演练

用于发现人物声音、试验冲突与检查选择是否可信。它是作者的探索草稿，不是新正史；用户要求正文时演练结束后仍须写实际场景。

## 给角色的最小上下文

提供人物ID、当前章/场、眼前目标、对谈对象、关系状态、已知事实及不能知道的信息。不给他整本结局再要求“假装不知道”。没有人物证据时先声明少量假设，不用人格测试标签替代角色。

用两至三个问题或一段具体争取开始：对方不肯给钥匙、要离开、要求解释账目。角色只从自己的证据回答，可以回避、误读、停住、开玩笑或反问。不要让每个角色准确讲出自己的潜意识。

## 观察而非背台词

记录他先问什么、怎样争取、什么时候改策略、哪些词反复避开。把这些变成正文可用的动作与语言规律，而不是堆口头禅。试验“同一坏消息由两个人分别得知”，检查回答是否可互换。

退出角色后标记：原设定支持的选择、待作者采纳的新细节、出现矛盾的地方。没有被采纳的即兴经历不得自动写进人物小传或后续事实账。

输出按任务可为一段对话、一份声音差异表或一个可替换场面。演练不需要真实联系演员，也不能伪装成真人试读。

整合方向参考 character-sim；改写为与本项目权威源、有限知情和采纳流程兼容的短演练。
