# 对抗力量与反派设计

用于反派扁平、主角赢得太容易、对手突然全知。对抗可以来自亲人、机构、自然或价值冲突，不需要每个故事都有恶人。

为对手写与主角同样具体的目标、资源、损失、盲区和行动。他的计划需要适应主角造成的变化，不能永远只在办公室说狠话。说明他为什么选择这种手段、为什么不能轻易换一个更简单办法。

权力分维度看：钱、人脉、信息、合法身份、时间、情感依赖和现场能力不必集中在一个人身上。对手可以在一个维度强、另一个维度脆弱。限制一旦建立，高潮不能因为需要抓人就忘掉。

区分能理解与被原谅。创伤背景可以解释某些倾向，但不自动抵消伤害；偶尔善待下属不能当作作者替其洗白。主角有错也不意味着双方所有行为等价。

逐次对抗记录`对手已知｜他认为主角会怎么做｜本次行动｜主角反制｜他获得的新信息`。身份揭露需要具体依据，不能从“他很聪明”跳到所有密码与秘密都知道。

交付对抗图和一场双方都在争取的戏。主角胜利利用已经建立的能力、联盟或对手盲点，而不是突然给反派降低智力。
