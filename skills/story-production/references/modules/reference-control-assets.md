# 参考与控制素材管理

提示词无法稳定控制人物姿态、背景透视或相机轨迹时，先核对模型工作流是否真的接受相应条件。身份参考、衣装、深度、姿态、遮罩、首尾帧和相机参数承担不同任务，不能把一张漂亮人像当成全部控制信息。

参考图与控制图应记录来源、裁切、分辨率、镜头、角色、服装阶段及文件哈希。姿态的左右和关节拓扑、深度的近远方向、遮罩的白黑含义、相机内外参/坐标系/单位都需要对应工作流说明。错误约定会比没有控制更糟。

ControlNet的此处固定来源主要针对SD1.5图像条件，CameraCtrl main针对AnimateDiffV3，SVD为另分支。不能把它们的输入直接当Wan、LTX、Kling等模型通用参数。先做小段对照，未运行的控制条件标待验证；不自动下载权重或承诺去除全部AI感。

字段、运行命令与验证范围见[交付扩展手册](../delivery-extensions.md)。
