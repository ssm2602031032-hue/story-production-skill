# 完整镜头信息的分层提示词包

全面的信息放在镜头工作包中：来源与作用、主体状态、动作首尾、空间机位、光线材质、对白、音轨、剪辑关系、参考条件和失败后的覆盖方案。给具体生成模型的文字只使用该模型需要且能接收的层。

同一场可有宏观结构、场面调度与单镜动作，但不能把所有层次同时塞进一个视频提示词。导演稿解释为什么，生成稿明确看见/听见什么，参数和资产引用按接口单独传递，剪辑与后期任务另列真实状态。

先保护主体、行动、空间和首尾状态，再压缩重复形容词。没有一种固定单段长度、英文顺序或负面词表适合所有模型；核对实际版本后适配。输出说完整，不意味着已生成媒体或无需审片。

工具、输入和使用边界见[剧本到情境剪辑](../script-to-edit.md)。
