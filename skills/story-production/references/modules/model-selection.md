# 模型与任务匹配

先选任务：文生视频、图生视频、首尾帧、控制视频、音频驱动或视听联合生成。再按显存、时长、尺寸、参考条件、许可证和部署方式选具体模型及管线，不能只比参数量。

同一家族的基础、蒸馏、音频驱动和专用控制模型能力不同，采样步数、引导与LoRA不能随意混用。公开权重或源码不自动等于所有地区、用途都可自由商用。

本包模型资料以固定提交的官方文档为依据，注明核验日期和未验证范围。官方示例帧数用于保守预设，不冒称最大长度。上游升级后先核对配置，不把旧参数默认为最新。

模型原生帧率与成片帧率不同，需要保持时长的转换；超分辨率不是原生细节，补帧也不是实际生成了正确中间动作。评估应包括输出的可编辑性与失败成本。

输出选择依据、能力缺口、可行替代和待实测镜头。不会把任一模型宣传为所有任务的绝对第一。
