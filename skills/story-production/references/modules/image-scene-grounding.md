# 从场景事实写出图片质感

用于用户提供参考图片/带提示词截图，要求学习构图、光线、生活感和材质，或写一张有明确视觉中心的生图提示词。它不要求所有画面暖黄、浅景深、人物微笑或同一种电影风格。

## 可迁移的写法

先写观众第一眼应看见的主体与动作，再写哪些环境信息帮助理解它。配角/次要物件的姿态、位置和清晰程度支持主注意中心；人数、道具和动作数量按当前故事需要决定，不能用“热闹”随意加人。

把图像组织成三层：前景有什么遮挡或引导，中景谁在做什么，背景保留哪些地点线索。层次不是强制三层全满；小产品静物或空旷场景可以有很少元素。不能让遮挡挡住关键手部接触、产品功能或需要读清的文字。

光线写成因果链：实际光源 → 方向/软硬 → 被照物体 → 阴影、反射或透光表现。门窗日光、实景灯、火光等只有在当前场景存在时才用。尘埃、烟气和蒸汽需要相应环境与光照才可见，不是每张图默认添加的“电影感滤镜”。

材质写差异和行为，而非所有表面都同样漂亮。粗织布的褶皱、釉面的连续反射、哑光橡胶和粗糙木材应各不相同；人物手部与物件的接触也要有明确关系。生活痕迹来自真实活动，不为了“真实”盲目塞满杂物、污渍或磨损。

情绪通过注意方向、手势、姿态和关系距离表达。笑容可以来自交谈中的某一瞬间；悲伤不必自动变成泪水，喜剧不必人人夸张做表情。镜头的注意中心必须与情绪信息所在位置相符。

## 先检查冲突

- 主要面部和手部不在同一焦平面时，极浅景深可能使其中一处模糊；按叙事需要选焦点或调整机位，不同时命令所有主体清晰与超浅景深。
- 正向文本要求柔糯、半透明或奶油质感时，负面列“塑料皮肤”不会自动消除蜡感。先改材料目标和照明，再比较结果。
- 旧场景可用年代一致的器物建立可信度；现代题材不沿用“排除现代物件”等负面词。
- 相机/镜头型号、分辨率口号和一长串画质词是描述或参数，不能证明输出用了真实设备或改善了质量。

输出完整制作说明、精简生图文本与可选平台参数分别保存。负面提示词只在实际平台支持时放入正确字段；不要把截图中的`--v`、`--s`、`--c`等尾缀复制到所有图像/视频模型。
