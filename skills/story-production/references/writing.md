# 从主题到完整作品

## 把主题变成可以发生的故事

主题是出发点，不是反复说给观众听的答案。用一个具体处境检验它：谁想改变现状，对方为什么不能轻易让步，怎样的代价会使选择变难。主人公应当有在开篇可见的能力，也有会造成损失的习惯；最终改变通过行动体现。

先写一个含结局的故事摘要。摘要用于检验因果，并不作为正文交付。每个主要段落至少能回答：

| 问题 | 需要的证据 |
| --- | --- |
| 他为何现在做这件事？ | 触发、期限、承诺或损失 |
| 他为什么会选这种办法？ | 已展示的能力、偏见与可用资源 |
| 结果为何导致下一段？ | 选择留下的新处境 |
| 观众为何关心？ | 关系、具体得失与不确定性 |
| 结尾为何只能这样到来？ | 前文建立的约束和最后选择 |

不必让每场都反转；休息、观察、共同劳动和喜剧场可以累积关系。但如果两场连续提供相同信息和相同情绪，考虑合并，或让第二场真正改变局势。

## 类型感来自场面的作用

- 爽感：能力先有证据，反击改变实际处境，回报可见；对手失去控制有原因，不靠突然继承或陌生人解围，除非这正是用户选择并已建立的世界规则。
- 爱情喜剧：双方有独立目标与能拒绝的空间；笑点来自努力、误判和后果。误会被指出后需要人物选择，不能靠正常交流即可消除的误会撑满全片。
- 悬疑：记录观众和角色何时得知每条信息。误导是对真实线索的合理误读，不能靠镜头故意伪造事实。揭露时回看前文应能成立。
- 动作：每个主要场面改变目标、资源或关系；先交代地理和限制，再用速度或危险兑现。规模递进不等于不停增加爆炸或追逐。
- 奇幻与穿越：能力、次数、窗口、代价和例外要一致。验证最明显的替代方法，避免结尾临时添加禁止条款强迫牺牲。
- 长剧：每集有自己的行动与结果，季线不断改变；不能用每集复位的误会代替发展。支线需有独立欲望并实际影响主线。

这些是决策提示，不是必须混进每部作品的元素。用户选择的类型与风格决定取舍。

## 场景与对白

进入场景时已经有人在做有意义的事。让空间影响行为：门、距离、噪声、围观者和出口能改变谈话策略。动作描述写可看见的变化；内心解释在小说中可以存在，在剧本中应转成可表演行为、必要旁白或明确主观表达。

对每段对白问“他想让对方怎么回应”。争取、拖延、掩饰、试探和共同开玩笑会产生不同句子。不同人物关注不同细节、以不同速度回答，不用统一金句腔替他们说话。

同一信息不要被台词、动作和作者解释三遍。保留生活中的绕路和停顿，但关键内容必须实际写出。写“他们商量好营救计划”时，检查是否正跳过了观众需要看的冲突。

## 小说的独立要求

每章具有稳定叙述视角、可感知场景、人物内心与叙述距离。对白之间的文字不应只是镜头动作搬运。时间跳跃要有读者能理解的锚点；信息可以被角色误解，但叙述不应无缘无故隐瞒他正在想的关键事实。

章节结尾可以是余韵、关系变化或新的行动需要，不必全部悬崖式中断。完成标准是整本承诺的故事推进与人物落点，而非每章机械相同字数。

## 改编已有小说

以用户指定版本为权威，记录保留的主旨、人物和结局。把内心戏转为选择、冲突和视觉行动时，保留其作用，不要求逐句复制。合并人物或事件必须检查后续知情、道具和关系是否仍有来源。

建立可追踪的映射：原章节 → 影视集/场 → 保留或修改 → 修改目的。允许影视叙事顺序与书稿不同；不要用影视重排后的时间线覆盖原书时间线。未改编的章节明确列出，而非从清单中悄悄消失。

## 控制篇幅而不填充

先估计关键段落需要的戏剧空间，再分配总长度。对白、动作、静默分别估计；快剪镜不能承载长段独白。短片减少要独立解释的关系与规则，长片让选择逐级产生后果，长剧允许多个已建立的欲望在不同集交汇。

若目标长度不匹配，优先调整戏剧内容、段落重复或目标范围。不要给几秒动作安排一分钟空白，也不要为满足镜头数量重复同一首尾锚点。
