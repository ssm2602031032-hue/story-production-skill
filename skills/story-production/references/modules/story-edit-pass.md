# 叙事粗剪与精剪

先把每个保留片段对应到原著段落/剧本场号，写明它改变了什么：观众新知道的信息、人物选择、关系反应或行动结果。粗剪优先验证完整因果和结局，精剪再调整注意力、情绪进入点与离开点。

切走前检验观众是否已经看见关键行动的完成态；保留反应镜不等于拖长空镜。剪掉说明性对白后，确认信息是否仍在可见行动里。不能用快剪掩盖人物为何改变主意的缺场。

将补写台词、补生成镜头与仅重排素材分开记录。剪辑中发现更好的故事解法时，依据授权同步改编稿与制作记录，不悄悄改小说正史。已有源稿的story_ref和edit diff可追踪实际联动。

具体字段、命令、依赖与执行边界见[剪辑工作台手册](../editing-handbook.md)。
