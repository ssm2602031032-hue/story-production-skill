# 实际媒体的技术检查

用户已有视频文件、要进入剪辑或怀疑错速/冻结/黑帧时使用。PyAV可读取编码和逐帧时间戳，本包 `media_qc.py` 报告分辨率、平均帧率、声明时长、实际解码范围、音轨信息及粗略重复/近黑帧告警。

默认只解码开头240帧；必须看 `entire_video_decoded`，不能以开头通过宣布整片合格。`--max-frames 0`才全片解码，长片会耗时。SHA256会读取整个文件用于身份核对，文件哈希不代表画面已逐帧检查。

对照制作计划的fps、尺寸和帧数。29.97与30不是同一速率；原生生成帧率与剪辑帧率不同，应明确选择重采样/补帧/变速并记录结果，不能仅修改标签。持续非均匀时间戳需先做帧率规整，重新检查实际导出文件。

粗略灰度指纹相同可能是合法静止镜头；黑帧可能是设计转场。告警用于定位复看，不能自动删除素材。当前工具不输出每个疑似帧的位置，需播放器或进一步检查定位；重复帧统计不等于真正的运动平滑度算法。

技术有效不证明皮肤自然、手指正确、人物一致、对白口型同步或故事好看。接下来按[真实摄影诊断](realism-diagnostics.md)记录观测时间和修法；VBench方法见[视频指标解读](video-metric-reading.md)。安装与命令见[工具手册](../integration-tools.md)。
