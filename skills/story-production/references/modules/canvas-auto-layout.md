# 分组排版与依赖自动布局

先确定语义组与阅读方向，再计算坐标。阶段网格适合制作管理和同镜头横向核对；ELK/Dagre式有向图布局适合分支依赖。自动布局引擎不知道剧情，不能代替作者定义事件顺序和素材用途。

约束节点尺寸、组内间距、列间走线空间、标题区、状态区和全文入口。长文本移入详情，避免靠缩小字体塞满卡片。复杂连接考虑分板、共享入口或依赖视图，而不是让连线穿过素材。

本包stage-grid输出无卡片重叠的分组板，本地路线避开卡片内部；可选ELK适配实际运行layered布局。两者都保留ID与关系含义，原生JSON Canvas客户端可能重新绘制连线。未在原生应用检查的部分明确记录。

每次输出重开规范与预览，核对关系是否连到正确节点、文字能否读、分组是否完整。规则通过但人看不懂时，应调整信息架构而非再加颜色。
