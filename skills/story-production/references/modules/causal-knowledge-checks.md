# 因果与人物知情检查

先读原文再抽出改变局势的事件：发生时间、必要前因、谁获知什么、后来谁据此行动。工具用有向图的依赖关系检查声明的数据；不从一句摘要推断人物动机，不给故事打自动合理性分数。

每项获知要说明途径和具体原文位置；同一事实可以有人知道、有人误信、有人不知道。此工具的fact表示作者已确认的信息，误信另建带语义标签的条目，不能自动合并成真相。同一时刻先听到再行动，要通过两个有序事件或明确前因表达。

故事时间与呈现顺序分开。倒叙正常；穿越或闭环世界需要定义各世界线和因果轴，不能机械使用历法数字后宣判世界规则错误。NetworkX提供图论参考，本脚本独立采用标准库实现，不必安装它。

字段、运行命令与验证范围见[交付扩展手册](../delivery-extensions.md)。
