# 场景欲望、策略与后果

写场景前先用一句话说明人物此刻希望改变什么、阻力来自哪里、准备怎样行动，以及失败/成功会改变谁的处境。把策略写成可执行的行为，不只写愤怒、焦虑或关系升温。结果可以是决定、知情变化、关系重新定位或付出代价；不要求每场强行反转。

正文让这些变化发生。人物说话是在争取、回避、试探、掩饰或保护什么；对手也有资源与局限。安静观察、独处和过渡只要承担信息、体验或余波，仍可保留。不要用抽象结构卡替代完整动作和对白。

修订时回到人物有没有更直接的替代办法、为什么偏偏现在必须行动。若删掉一段后结果仍一样，检查是否重复；若删掉后选择失去原因，应补回前提而非只加更强烈情绪。
