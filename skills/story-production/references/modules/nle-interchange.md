# 剪辑软件交接与回读

向Resolve、Premiere或其他NLE交接前，记录目标软件版本、可用导入器、项目帧率、画布、时码基准和媒体路径。先在独立时间线试导入并核对范围，不覆盖用户正在剪的主时间线。

本包真正导出并读回OTIO，保留画面及独立声音位置；EDL路径仅支持单层画面、24/25/30非丢帧，需要明确picture-only。所有源时码按文件帧从零计，不假冒拍摄机时码。短reel标识有映射，避免同名前缀丢失来源区分。

原生Resolve自动化应以安装版本随附的API说明及真实返回值为准；不照搬上游关于免费版/Studio权限的笼统说法。这里没有启动Resolve或证明商业软件导入成功。OTIO音量/淡化元数据不等于编辑器已自动应用。

具体字段、命令、依赖与执行边界见[剪辑工作台手册](../editing-handbook.md)。
