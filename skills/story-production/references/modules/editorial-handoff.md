# 从镜头计划到剪辑工程

用于把已有生成素材整理给剪辑师或导出时间线。OpenTimelineIO保存编辑结构，本包导出真实 `.otio`，不把CSV改扩展名冒充工程。是否能被目标剪辑软件直接打开取决于其版本、插件与适配器，交付前做实际导入验证。

以 `film_pipeline.py build` 得到的 `shot-plan.json` 为剪辑计划，另建镜头ID到实际媒体的映射。每项含相对于映射文件目录的 `path` 和 `source_in_frame`。视频先全解码核对实际fps、可用帧数与取用范围；不支持的变速/VFR先在外部明确规整。本工具不会替用户决定补帧风格或偷偷变速。

镜头按计划的排他尾帧范围顺序组装。源媒体入点与成片入点分开；多段生成任务需要先选片和组装为该镜头的素材，不能把生成任务列表直接当作最终剪辑。纯后期镜也需要真实导出画面，或显式保留缺失引用。

缺素材默认停止导出；只有用户要预规划工程时使用 `--allow-missing`，工程元数据保留缺失镜头和 `planning-missing-media` 状态。齐全工程标为 `picture-assembly-only`，仍未完成音轨、调色、转场设计、配音和混音，也不代表已渲染成片。

OTIO使用相对媒体路径，交接时保留工程与媒体的相对目录结构。实际重开检查片段入出点和总帧数，再到剪辑软件核对声音、画幅、帧率和缺失链接。命令与最小输入见[工具手册](../integration-tools.md)。
