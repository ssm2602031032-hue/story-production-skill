# 创作模块目录

本库共40个按任务调用的模块：12份昆卡技能原文快照、28个本项目扩展模块。不是40个同时执行的步骤。先确定用户要做什么，只读本阶段确实需要的2—3份；下一阶段再按问题加载。

## 快速路由

| 请求 | 优先模块 | 需要时补充 |
| --- | --- | --- |
| 只有主题，要完整新作 | 构思、人物、结构 | 对应媒介与类型 |
| 只改对白 | 对白 | 角色演练；不重构整季 |
| 只审现稿 | 综合改稿、连续性 | 读者体验；不给未授权重写 |
| 小说正文/文风 | 小说文风、场景 | 长篇记忆、风格实验 |
| 长篇剧集 | 全季开发、分集结构 | 长篇记忆、跨集连续性 |
| 小说影视改编 | 改编、结构 | 视觉/声音外化及改编映射 |
| 悬疑/惊悚 | 悬疑线索、连续性 | 研究、读者体验 |
| 爱情喜剧 | 爱情、喜剧 | 对白，保留真心时刻 |
| 动作/运动 | 动作与代价 | 视觉、制作约束 |
| 奇幻/科幻 | 世界规则、结构 | 连续性与替代方案测试 |
| 网文/逆袭/连载 | 连载回报、人物 | 长篇记忆；不凑字数 |
| 视觉或声音专项 | 对应专项 | 已定正文、制作约束 |

## 模块协作规则

用户约束和本Skill入口优先。上游快照作为局部方法，不触发安装其他包、长期停工访谈或外部发布。提出新设定的模块要把它标为提案，采纳后才进入正史。审读只报告有文本依据的问题，不为体现模块数量凑报告。

`creative_tools.py plan`生成的路线仅供代理选择，不会生成正文，不会自动安装或执行其他技能。`--task`、`--mode`和用户明确范围优先于关键词推断，推断错误时直接覆盖参数。输出的read_batches是可按阶段使用的小组，不要求一次读完全部。

若同时要求整部全套，所有已承诺部分仍须完成；按需加载只是减少无关上下文。若只改一场，不因库里有全季模块就扩写整季。

来源与许可见[整合说明](integrations.md)，机器校验只检查引用与状态，不代表文学效果已得到真人验证。
