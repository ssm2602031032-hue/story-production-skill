# 原文到镜头的改编追踪

源小说、剧本、改编方案与视觉生产记录各有用途。先引用实际读到的短段落或集场位置，再说明该内容承担的因果、信息和情绪功能。不能只换词就算改编，也不把未来计划当成原文已经发生的事实。

对重要事件记录目标镜头；被省略的章节或桥段说明损失，检查后续是否仍依赖它。把内心描写外化时可以选动作、空间、物件、声音或画外音，具体手法应保留该段功能。允许题材变化时核对新人物是否还拥有旧权限、资源和知情。

工具核对版本、准确引文和映射缺口，无法自动读懂整章所有隐含内容。章节被一条引文覆盖不证明完成全章改编；用原文与成稿通读补足。明确局部任务只追踪该范围，不借检查扩写整部作品。

工具、输入和使用边界见[剧本到情境剪辑](../script-to-edit.md)。
