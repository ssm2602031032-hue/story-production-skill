# 长篇记忆、事实与续写交接

用于长小说、多集剧与跨会话修订。保存能够改变后续决策的事实，不把整段聊天复制成知识库。

## 四种信息分开

1. **正史事实**：实际正文已发生或用户确认的设定，带章节/集场引用。
2. **人物相信**：此人当时怎么理解、依据是什么；错误信念也需要保存。
3. **计划**：未来可能发生的回收，未写之前不能说已完成。
4. **废弃提案**：保留简短原因，避免下次误恢复。

每完成一个有变化的单元，更新角色当前位置、目标、知情、关系、物件、伤势和未完承诺。常识不必反复抄录；没有变化的条目不制造新版本。

## 交接包

交给下一位写作者的内容为：用户硬约束、当前有效版本、刚发生的后果、下一单元必须接住的问题、相关局部正文、不能提前使用的信息。不同任务给不同上下文：写下一场不需要整部技术导出说明；独立首次读者不应拿到答案。

事实账是可检索索引，不替代权威正文。记录冲突时引用两端事实，修改后更新受影响条目。用户明确要改某规则时记录生效范围与需返修的章节，不能暗改旧定义又声称自然连续。

## 恢复工作

先读取checkpoint和最新完成单元，再确认源文件与输出版本。区分草稿完成、审校完成和媒体完成；不能把场号已列齐误当内容齐全。目录创建或模型上下文耗尽都不是结束理由，但缺必要材料时应准确报欠缺范围。

整合方向参考 story-memory；本模块不要求额外AGENTS.md访谈或外部代理，已有项目结构可以继续使用。
