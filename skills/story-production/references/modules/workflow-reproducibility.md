# 工作流复现与版本

保存模型准确名称/修订、检查点哈希、VAE、文本编码器、LoRA及权重、工作流提交、节点版本、采样器、步数、引导、种子、尺寸、帧数、帧率、参考素材和提示词版本。缺项标未知，不从文件名猜版本。

ComfyUI界面工作流与API格式不是同一个JSON。模板能解析不代表当前机器所有节点与模型已安装；先在匹配版本打开、核对，再由实际环境导出API任务。不要凭空构造节点ID提交。

一次修改一个主要变量，保留之前可用结果和设置。输出文件名关联镜号与尝试号，接受哪一版有明确记录；失败文件不能覆写为成功名来隐藏问题。

公开项目只收录可再分发的工具与说明，模型权重、第三方素材和用户私稿按各自许可处理。本包默认准备资料和任务，不自动安装大型依赖、下载权重或调用付费服务。
