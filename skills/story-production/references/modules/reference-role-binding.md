# 参考角色与模型输入绑定

每个参考明确继承什么、排除什么。身份图负责形体与造型；风格图主要提供光线/色彩/材质方向；动作示意提供空间或时序。风格图中的人物、服装、车型和布景不应自动迁入当前作品。

普通I2V需要真正的单个场景首帧，不能把多格角色表直接当开场。多资产首帧需分别核对可见主体、道具和空间。文件存在与人工标记只说明准备状态，模型能否正确遵循仍需样片。

VACE等项目可提供特定基础模型下的图、视频、遮罩组合；白模可用于对齐几何与机位。确认实际模型版本和输入角色后再接入，不把某个旧模型的控制格式当所有平台通用能力。

字段、例子与工具用法见[通用影像执行手册](../visual-reliability.md)。
