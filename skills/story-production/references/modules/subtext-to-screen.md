# 潜台词与内心戏转成视听

先判断这句心理描写让读者知道什么，以及人物愿不愿让别人知道。可见行为可以表达犹豫、回避与选择，但不要把所有复杂内心都替换成握拳、掉泪或夸张微表情。

选择能承担功能的视听通道：一句答非所问、停在门外、没有递出的物件、声音突然变远，或明确的主观旁白。改变谁看见或听见信息会改变剧情，必须同步知情与后续反应。纯心理解释留给导演稿，生产提示词写真实可呈现的部分。

对克制或主观风格，不强制“全部外化为身体动作”。采用旁白时写出实际台词与作用，避免它重复可见画面；用动作时让准备和结果可读，再判断是否需要特写。
