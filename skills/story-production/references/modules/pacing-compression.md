# 节奏、删减与有效扩写

用于中段拖沓、篇幅过短、需要缩减演员/页数或章节密度不均。先确认是信息重复、选择不足、表演容纳不足还是目标篇幅不合适，不先机械提速。

给段落标记它独有的信息、决定、关系变化和感官体验。两段作用完全相同可合并；若后一段使先前理解改变，就不应因表面相似而删除。安静并非天然拖沓，激烈也可能原地重复。

删减表记录`删什么｜失去什么｜必须转移到哪｜新的进入/退出状态`。短一页但丢掉关键知情来源，不算改好。镜长减小后完整对白必须重新试排，不能只改Excel数字而把SRT和AI分段留在旧版本。

扩写优先增加更难的选择、具体阻力、关系后果或重要经历。不要把一句行动拆成十段同义描写，不用大量回忆延迟已经能完成的决定。用户要求长篇时，先让故事需要那么长，再让内容自然占据篇幅。

比较前后用实际文本与变化的体验：承诺是否更清楚、重要决定有没有时间、读者会不会重复等待同一答案。估计阅读/片长时注明方法；没有真实配音或预演，不能把字数换算当锁定片长。

输出修订稿、取舍清单和受影响的连续性位置。用户指定不能删的场面保留，换呈现方式也要说明损失。
