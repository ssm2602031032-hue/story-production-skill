# 两张图文截图中的图片提示词方法

## 证据范围

来源为用户提供的两张截图，用户关联到抖音作者“Chill^_^Puppy”的[图文作品](https://www.douyin.com/note/7690847701923138843)，2026-11-01读取截图。原网页正文未通过浏览工具独立读取，作者完整工作流未取得。

第一张可见人物围绕灶台活动，一位女子位于较清楚的视觉中心；第二张可见女子俯身操作织机，橙色叶片在近前景形成遮挡。两张均包含可读的Prompt区。以下只用少量必要短语解释方法，不随公共Skill分发截图或完整原提示词。

这里的“提示词”指截图显示的文本，不证明它就是生成最终图片时的完整输入。平台参数、参考图片、种子、模型检查点、选择次数和后期处理仍未知；单张截图无法检验视频运动或跨帧一致性。

## 截图文字与画面的对应

|可见写法/画面|可迁移的方法|不应顺手照搬的内容|
|---|---|---|
|第一张文字反复确定中心人物，画面中心的脸和身体更清楚|先建立一个主要注意中心，再让配角和器物支持它|固定人数、炒菜活动、某种人物造型|
|第二张前景叶片遮住一部分边缘，手、脸和织线集中在中景|用遮挡、引导线与清晰度建立空间层次|橙色植物、庭院、织机和所有画面都必须浅景深|
|文字指定门窗/日光、火光等来源与照射效果|描述光源如何作用于当前材料，形成明暗与反射|所有题材暖黄、所有空间都要火光/尘埃|
|两张都把情绪放在活动中的姿态与交流里|用正在发生的动作获得生活感，明确凝视与手势对象|让所有人物微笑，或把每一场都改成热闹群像|
|棉麻、木构件、石面、烟气/蒸汽等分别出现|用当前环境中成立的材料与状态建立触感|无条件增加做旧、污渍、烟尘和随机杂物|

画面支持的观察是：主体与背景有选择的清晰度、暖色高光与较暗背景形成分离，局部材料和空气介质帮助营造氛围。不能仅凭截图断言准确曝光、焦距、光比、皮肤细节水平或生成参数的因果效果。

## 参数和措辞需要谨慎迁移

第一张可辨认的尾缀包含`--v 8.2`、`--ar 16:9`、`--s 260`、`--c 5`；第二张包含`--ar 16:9`、`--s 285`、`--c 5`。这是带特定平台语法特征的文本；这里不据此认证实际模型版本，也不把数值写成通用推荐值。负面列表是否被放在平台真正支持的字段中，截图不能确认。

第二张出现相机/镜头名称及f/1.2写法，不能证明图片由真实相机拍摄。若当前故事要同时看清不同距离的脸和手，应根据所需焦平面重新设计，不盲从最大光圈。

截图中“半透明柔糯肤色”“奶油般散景”强调柔美，可能适合该作者想要的观感；在要求普通实拍或细节清楚的项目中，它们也可能加重蜡感或背景糊化。负面写塑料皮肤并不能保证抵消正向描述。合理实验是仅替换材质段或景深目标，固定其他条件，比较完整输出。

## 已融入的通用方法

1. 将人物/产品的注意中心、动作、前中后景、实际光源、材质反应和情绪关系写成可见条件。
2. 把风格、不可变主体和平台参数分层；复用方法时重写当前场景的名词与动作。
3. 检查焦点需求、材料目标与负面词是否互相打架。
4. 先做固定条件的单因素图片对照，再把批准图转为独立动作契约；不把静帧美感当视频质量证明。
