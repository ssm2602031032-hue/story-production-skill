# 改编覆盖与可生成动作

用于小说改编电影、长剧或短剧。参考 write-screenplay 的节拍覆盖与动作拆解；保留当前用户的媒介、语言、时长和类型，不能把所有故事改成一分钟反转短剧。

先从原文抽取决定因果的事件，给每项源章节、人物目标、行动、结果和不可丢失的信息。建立“源事件 → 目标集/场 → 保留/合并/移位/删除 → 理由 → 受影响伏笔”映射。对删去的事件给出因果替代，统计覆盖只能发现遗漏，不能证明改编成功。原书、改编剧本与制作分镜分别保留。

内心活动的处理依据叙事：可用可见选择、环境反应、画外音、主观声音或省略，不要求把每个念头变成夸张动作。人物不愿交钥匙，可以在对方伸手后仍把钥匙压在掌心；无须额外增加哭喊。

## 动作按失败点拆，不机械碎剪

为每镜写起始姿态、主要动作、接触关系、结束姿态、邻镜承接。一个连贯简单动作可以完整生成；多次抓握、遮挡换手、多人交叉、复杂旋转或背景大量揭示时，先拆成可验证的短段。剧情中的完整行为不能因拆镜丢掉关键结果。

例如“抓钥匙、转身跑下楼、开车离开”包含不同空间和接触状态：

|镜头功能|首态与动作|尾态与承接|
|---|---|---|
|交接信息|桌边固定中近景，右手拿起钥匙|钥匙仍可见，右手握住|
|离开关系|门边中景，人物走出画面|右手持钥匙，门内人物没有跟随|
|出发结果|已建立停车位置的车内/车外镜|先交代驾驶者与车启动，再决定是否需要运动镜|

镜长依据实际动作与对白预演。拆出的生成段时长不等于成片镜长；素材入出点、余量与原生帧率交给制作计划记录。不能仅凭“单动作”保证肢体不变形，关键交接仍需看全段。

本模块写出映射和分镜文本，不自动解析任意小说、生成影像或验证物理。与[影视改编](../upstream/kunka/kunka-adaptation.md)、[动作物理](motion-physics.md)及[工具手册](../integration-tools.md)配合。
