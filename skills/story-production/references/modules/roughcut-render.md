# 本地粗剪预览渲染

从已选素材和明确的剪辑决定生成审片MP4，先验证源文件哈希、实际帧率、可用帧与声音格式，再生成可检查的命令计划。用户已要求本地剪辑时完成该范围，不增加无理由的逐步许可环节。

画面以排他尾帧区间拼接，全部原画幅等比缩放并加边。声音来自显式WAV列表；源视频内嵌音轨按明确ignore策略处理。没有音频输入就是无声审片，不得暗称已配音或混音。

每次渲染后重新解码核对实际帧数，失败文件标未验收。技术通过后还需实际播放切点和听音轨。粗剪预览不包含未执行的字幕烧录、调色、片头、溶解或影院母版处理。

具体字段、命令、依赖与执行边界见[剪辑工作台手册](../editing-handbook.md)。
