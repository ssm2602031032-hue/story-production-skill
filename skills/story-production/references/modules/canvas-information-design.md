# 画布的信息架构与阅读路径

整理前先问这块画布帮助谁完成什么决定：找素材、比较候选、读故事顺序、审看问题，还是理解模型依赖。当前用户已经明确目的时直接按该目的设计，不重复询问。

把素材角色和制作状态分开。参考图不等于已批准首帧，提示词不等于生成片，候选片不等于已选成片。稳定ID连接源稿、场景、镜头和素材版本，状态用文字和少量颜色共同表达。

制作板可用场景分组、阶段分列、镜头纵向对应；时间线按故事/播放次序，依赖图按真正的输入输出关系。共享素材单独放置并建立引用，避免到处复制。两个目的冲突时做两个相互可导航的视图，不强塞到同一巨图。

卡片只显示标题、状态、关键摘要或缩略图，完整提示词/来源/审看记录放在可打开详情中。组标题、留白、对齐和连接标签优先于装饰色；边线应解释关系，不能只是“看起来有流程”。

实例、格式和运行入口见[画布手册](../canvas-handbook.md)。
