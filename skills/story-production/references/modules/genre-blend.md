# 类型承诺与混合

先说观众主要来经历什么，再选次要类型。一个故事可以只有一种类型；不规定必须混合三四种，也不要求照搬某理论的全部节拍。

| 类型侧重 | 需要兑现的体验 | 容易失效的位置 |
| --- | --- | --- |
| 悬疑/推理 | 可追踪的提问、验证与揭露 | 全知答案、线索只在结尾出现 |
| 惊悚/恐怖 | 已知或逐步可感的威胁、脆弱与选择 | 反复廉价惊吓、规则随意变化 |
| 爱情 | 具体吸引、互相看见、靠近与代价 | 一方只是奖品，误会没有依据 |
| 喜剧 | 人物努力产生的偏转和持续后果 | 只有段子，没有情境 |
| 动作/运动 | 可读空间、策略与身体后果 | 不停升级规模，剧情原地踏步 |
| 奇幻/科幻 | 新规则改变人的生活与选择 | 设定说明书，能力万能 |
| 家庭/成长 | 关系中的习惯、记忆与逐步改变 | 每场说教、突然顿悟 |
| 日常/抒情 | 细微差别、回响和时间体验 | 以“无冲突”为由堆积无变化场景 |

## 混合方式

用主类型决定结尾的主要兑现，次类型改变过程的压力或表达。例如爱情悬疑的真相应该改变两人如何信任，而不是最后十五分钟临时换成另一部犯罪片。喜剧与悲伤可以并存，但发生真实损失后，人物反应不能仍按上一场的小麻烦处理。

为每个主要段落标记“本段承诺什么、完成了什么、带入下一段什么”。不必平均分配类型标签。若删掉所有表面符号后故事仍有独特关系与行动，类型才已进入结构。

风格参考拆成光线、信息顺序、对话密度、留白、动作规模等可比较选择。只给两个有区别的试片，不无限生成近似方案。类型试验失败时回到用户想看的体验，而不是给作品贴更多标签。
