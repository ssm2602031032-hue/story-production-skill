# 动作衔接与空间因果

先让观众理解谁要做什么、东西在哪里，再安排覆盖镜头。每镜应推进信息、选择、行动结果或关系；不要把剪辑好等同于镜头越短越好。一次停顿也可能是人物作决定所需的内容。

剪切前后核对手、道具持有人、座位、视线、运动方向和动作阶段。插入反应镜不会自动重置空间方向；方向改变、时间跳跃或状态变化需有可见桥接或明确的叙事依据。不能靠换镜把没完成的交接变成已完成。

在生成前解决覆盖需求，留入点/出点的动作余量。素材真实失败时选择补镜或修复，不能靠高密度特效掩盖空间不明。契约审查与已有编辑版本比较配合，成片仍要实际逐段观看。

字段、例子与工具用法见[通用影像执行手册](../visual-reliability.md)。
