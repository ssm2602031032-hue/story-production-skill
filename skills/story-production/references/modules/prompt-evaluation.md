# 提示词对比与失败诊断

“更好”先对应指标：叙事行动是否发生、身份与空间是否稳定、动作是否可读、表演是否到位、是否能接邻镜。不要仅用漂亮静帧替代整段视频评价。

比较A/B时固定模型与版本、工作流、尺寸、帧数、种子组和参考素材，只改变本轮要检验的提示变量。可用多个种子减少偶然性，但实际尝试数受预算约束，未生成的测试留空。

记录失败类别、出现帧段、严重度、是否影响叙事、可否靠剪辑修复及下一次只改变什么。区分输入图问题、模型能力缺口、参数错误和提示冲突，不把所有失败都归咎于提示词不够长。

人工评分必须附实际输出路径与观察；模型自评不是市场或真人盲测。没有实测时只能交测试设计，不生成虚假的质量分数。最佳版本只相对于本任务、本模型和本轮证据成立。
