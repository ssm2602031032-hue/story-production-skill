# Fountain与FDX交换

用户需要在编剧软件继续编辑或交给协作者时使用。导出场景标题、动作、人物和对白，中文角色采用显式Fountain标记，FDX调用实际Screenplain接口，不将Markdown改名为FDX。

场号和镜头编号作用不同。每镜的动作可以保留为连续动作段，但不要把预剪秒数伪装成最终页数或按“一页一分钟”宣布片长准确。双声道、修订色、复杂页式、镜头资产和时间码并非此导出的完整往返范围。

实际解析检查之后，还要在用户要用的软件试开；保留JSON和制作包供后续修改。不要因为导出成功而重写用户对白或替换中文姓名。

字段、运行命令与验证范围见[交付扩展手册](../delivery-extensions.md)。
