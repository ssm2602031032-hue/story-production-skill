# 提示词回归与实验记录

用于修改提示词模板后防止旧问题复发。Promptfoo负责运行可重复的输入和断言；本包的离线provider仅检查有限的文本规则，不调用语言模型或视频模型。

运行 `prompt_regression.py` 导出可搬移的5例测试：固定机位基准、明确否定运镜、固定与环绕冲突、景深冲突、赞美词堆叠。坏提示词应返回FAIL，因此“测试通过”可能意味着正确识别出FAIL，不能说坏提示词被评为优质。更复杂的中文/英文语义仍需人工读，正则检查不是摄影理解模型。

按项目补充失败案例时，记录原提示词、观察到的具体错误、应当保持的约束。修改模板后运行旧例与新例，防止为一条样片过度拟合。不要只用自己希望通过的句子证明提示词有效。

## 三种证据分开

- 文本契约：语句是否存在已定义的矛盾。可以离线自动检查。
- 生成器遵循：实际输出是否执行了动作、机位、人物和服装要求。必须有实际视频和失败时间点。
- 观感质量：相机、光线、表演、纹理、空间与剪接是否可信。看完整视频和邻镜，保留主观评分者与依据。

固定同一模型版本、工作流、参考图和参数，用相同种子组比较A/B；不能因单个幸运种子说“全面提升”。基准A可用固定机位、一个可见动作、明确光源；B只改变一个因素。原始输出与超分补帧版本分开比较。未生成时状态是“待实测”，分数为空。

如改用在线provider，先确认当前用户的生成范围、输入内容与费用授权，不沿用离线测试的零费用假设。命令与已测版本见[工具手册](../integration-tools.md)，实际画面排查见[真实摄影诊断](realism-diagnostics.md)。
