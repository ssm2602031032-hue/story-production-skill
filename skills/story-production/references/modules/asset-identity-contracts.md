# 通用资产一致性契约

先确定当前项目真正需要保持的身份/几何，再定义可以随剧情改变的状态。人物身份与造型阶段、物件本体与持有人、空间布局与时段应分开。不要因为某个样例是黑色双门车，就把车、颜色或动作设成所有项目默认。

同镜多人、多物分别有资产ID和状态。单镜提示词只写当前可见的特征，其他身份信息留在契约中。手部特写无需额外生成脸；车辆后视无需把前格栅翻出来。看见的数量与完整对象的数量也应区分。

每个场景首帧记录它实际覆盖了哪些资产，连同文件哈希与人工审查说明。工具能检查声明是否一致，不能自动确认图像中真的是同一个人/物。模型ID、种子或重复一句“保持一致”都不是身份锁。

字段、例子与工具用法见[通用影像执行手册](../visual-reliability.md)。
