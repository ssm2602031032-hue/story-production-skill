# 整季承诺与兑现表

把主线问题、关系承诺和重要物件的用途分别列出，记录首次建立、再次提醒、实际兑现或有意开放的位置。检查集数跨度可以提醒遗忘风险，但不存在统一“隔三集必须提醒”的规则。

resolved需要具体兑现文本位置；仅在分集大纲写“揭开真相”仍是planned。open-intentional写出为何留白及本季已经完成的体验，不能用来掩盖漏写结尾。工具检查字段与顺序；审稿人仍要读铺垫和兑现两端，判断公平、意外和情感力度。

原文改变后复查相关条目与跨集人物状态。源自网文审稿的分层复核方法，不继承字数填充、固定代理数或未请求的自动改稿。

字段、运行命令与验证范围见[交付扩展手册](../delivery-extensions.md)。
