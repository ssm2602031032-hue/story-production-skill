# 小说电子书交付

在全文完整且通过源数据检查后导出EPUB阅读版。章节正文不改成摘要，作者署名、语言、标题和版本依据用户提供的事实。未完成的书可以按用户要求另做明确节选，不能把缺章藏在完整书名下。

本包生成EPUB 3容器、导航、书脊和XHTML，并检查内部XML和ZIP；官方EPUBCheck是另一个真实执行步骤。阅读器还需要看中文换行、目录跳转、段落与字体回退。格式验证通过不能证明文本没有错字，更不证明已获得发行渠道或授权。

保留novel.json为权威源。修改小说后重新导出新版本，不在电子书内偷偷修改故事使两份不同步。

字段、运行命令与验证范围见[交付扩展手册](../delivery-extensions.md)。
