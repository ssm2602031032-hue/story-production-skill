# 切点候选与剧情场次复核

用户已有成片/生成片段，需要定位意外切换、整理素材或复看剪辑时使用。PySceneDetect的AdaptiveDetector检测画面变化，输出帧区间。本包 `media_qc.py --detect-cuts`会实际调用它；不是生成一张预测表。

切点候选不等于剧本场号：同一场可以多次正反打，一个长镜也可能跨越多个戏剧段落。闪光、快速摇镜、车辆经过、遮挡和强光变化可能误触发；渐变和细微切换可能漏检。

先核对源fps与视频版本，再在每个候选前后播放，标为真实剪切、转场、光变、遮挡或未知。需要映射回剧本时，依据人物、地点、动作、对白与时码人工关联，并保留无法确定项。

生成镜头出现未要求的切换，优先缩短动作/机位要求，或明确单一连续拍摄并重新生成；提示词并不保证不会切。合法剪切不应为了“零切点”被误删。自动工具不修改或删除源视频。

输出采用 `start_frame` 与 `end_frame_exclusive`，尾帧不包含在区间内。全片检测独立于技术检查的开头采样上限；大文件要预留处理时间。命令见[扩展工具手册](../integration-tools.md)。
